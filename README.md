# Itz Fizz — Scroll-Driven Hero

Recreation of the reference [car-scroll-animation](https://paraschaturvedi.github.io/car-scroll-animation): a car drives across a road as you scroll, painting a trail behind it. The dark letters of **W E L C O M E I T Z F I Z Z** only show where the trail has passed, and four impact stats light up as the car goes by.

Two implementations of the same design are included (plus `static-build/`, a ready-to-upload copy of the site):

| Folder | Stack |
|---|---|
| `/` (root) | **Next.js 14** (static export) · React · **Tailwind CSS** · **GSAP + ScrollTrigger** · Lenis · **Bootstrap grid** |
| `wordpress-theme/itz-fizz-hero/` | **WordPress theme**, with vanilla **HTML/CSS/JS** + GSAP + Bootstrap grid. Everything bundled locally, no build step |

## Run the Next.js version
```bash
npm install
npm run dev        # http://localhost:3000
```

## Deploy to GitHub Pages
1. Push this folder to a GitHub repo on `main`.
2. Repo → **Settings → Pages → Source: GitHub Actions**.
3. `.github/workflows/deploy.yml` builds and publishes it (base path is set from the repo name).

Manual: `NEXT_PUBLIC_BASE_PATH=/your-repo npm run build` → static site in `out/`.

## Install the WordPress theme
Zip the `wordpress-theme/itz-fizz-hero` folder (a ready zip is provided) → **Appearance → Themes → Add New → Upload Theme → Activate**.
Edit stats/headline in `functions.php` (`itzfizz_get_stats()`), or override with `add_filter( 'itzfizz_stats', … )`.

## How the animation works
| Piece | Technique |
|---|---|
| Load | GSAP timeline: road wipes in, letters rise from a mask (staggered), car slides in, stat cards pop in one by one while numbers count up |
| Scroll | One `ScrollTrigger` pins the hero and scrubs a single timeline (progress 0→1) with `scrub: 1.1`, so motion glides to the scroll position instead of snapping. Lenis adds inertial scrolling |
| Trail | A full-width bar scaled from the left (`scaleX`); its edge always equals the car's centre |
| Letters | Car centre vs each letter's cached x → CSS variable `--f` (0→1) fills the letter. Only changed letters are written |
| Cards | Each card scales up (CSS transition) the moment the car passes under it |
| Performance | Only `transform` / `opacity` animate; positions are measured once per refresh, never per scroll event |
| Accessibility | `prefers-reduced-motion` shows the finished state with no pinning; headline has an `aria-label`; visible focus rings |

## Notes
- Stats are the reference's numbers (58 / 23 / 27 / 40 %); wording tidied to "Decrease" / "pick-up".
- The car (`public/car.svg`) is an **original illustration** drawn for this project, so there are no third-party image rights to worry about. Swap in your own top-view image (facing right) if you like; keep roughly a 2.1 : 1 ratio, or change `--car-w` in the CSS.
- Bootstrap is used for layout via a **grid-only** stylesheet (`container` / `row` / `col-*`, generated by `scripts/make-bootstrap-grid.js`). Bootstrap's own spacing utilities are deliberately left out: they are `!important` and silently override Tailwind's `px-5` / `py-5`.
- The stage is sized from the free viewport height, so cards never collide with the nav on short laptop windows or small phones. In WordPress it also accounts for the admin bar when you're logged in.
- See `HOSTING.md` for step-by-step free hosting.
